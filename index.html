管理学原理 · 期末复习导图

★高频考点（定义、分类、人物观点）P25 课件标注的教材页码点击节点上的 / + 折叠或展开
        • 根本矛盾 ★：人的欲望无限 vs 资源有限 → 需要协调
          • 生产：通过劳动向自然界要资源
          • 战争：通过掠夺他人资源扩展自身资源
          • 道德：通过教育约束个人欲望
          • 管理 ★：用科学方法提高资源利用率，以有限资源尽可能多地满足欲望
        • 共同劳动 ★：是组织或团队产生的原因，但不是管理产生的原因；两人以上一起劳动，必然产生相互协调问题，才需要管理
          • 个体差异：认识不同（思想）、追求不同（利益）、能力不同（工作分配）、个性不同（配合协调）
          • 资源有限：如何使用、如何决策，使目标最大化
          • 组织管理：把不同个体团结起来，以有限资源实现尽可能高的组织目标，更好满足每个个体的需求
          • 生产活动：资源筹措 → 资源转换 → 产品销售或成果处理
          • 三个背景：资源稀缺；内部活动成果需在外部实现；产品是生产者联合劳动的成果
          • 因此既要选对活动方向（产品符合市场需求），又要用对方法与技术（有限资源充分利用）
        • 组织形成要点：领导人发起、共同协作意愿、广泛信息沟通 → 共同目标、志同道合（能力互补）的团队、共同遵循的群体规范
        • 组织创立的关键要素：发起人（领导人）→ 共同目标；创业精神/协作意愿 → 创业团队；沟通畅通 → 组织规范
          • 手段：分工（发挥各人特长）、协作（形成集体力量）
          • 机制：成员双向选择、自由组合；能力互补、志同道合、沟通顺畅
          • 定位：确立群体认同的共同价值观和发展目标，是组织存在的基础
          • 激励：调动员工能动性，使组织充满创造力
          • 规范：明确规范、建立相互信任，是组织运作的基础
          • 泰勒（1911，科学管理奠基人）：确切了解你希望工人干什么，然后设法使他们用最好、最节约的方法完成
          • 法约尔（1916，《工业管理与一般管理》）：管理就是实行计划、组织、指挥、协调和控制
          • 孔茨与奥唐内尔（1955，《管理学》）：设计并保持一种良好环境，使人在群体里高效率地完成既定目标
          • 西蒙（1960，诺贝尔经济学奖，《管理决策的新科学》）：管理就是决策
          • 罗宾斯与库尔塔（1996）：和其他人一起并且通过其他人来切实有效地完成活动的过程
        • 综合定义 ★：为有效实现组织目标，管理者利用相关知识、技术和方法，对组织活动进行决策、组织、领导、控制并不断创新的过程
          • 目的：有效实现组织预定目标（保证活动顺利进行；用较少资源、合理手段实现）
          • 本质：协调（协调组织资源、协调组织与外部环境的关系）
          • 主体：具有专门知识、利用专门技术和方法进行专门活动的管理者
          • 客体：组织活动及其参与要素
          • 过程：包括决策、组织、领导、控制、创新的多阶段综合过程
        • 管理的实质：以有限资源实现尽可能多或高的目标的一种手段
          • 效率：用正确的方法做事，强调方法（正确地做事）
          • 效果：实现目标的程度，强调工作的有效性
          • 效益：用正确的方法做正确的事，强调决策（做正确的事）
          • 结论：既要讲效率，又要讲效果；课件写作"效果 = 效益 + 效率"
          • 人、财、物、时间、地点、信息、技术、产品、客户
          • 人力：被组织利用的劳动力
          • 物力：设备、材料、仪器、能源等，物尽其用、提高利用率
          • 财力：经济和财务资源的有效管理，保证计划完成
          • 信息：提高管理效能的重要部分
          • 时间：在尽可能短的时间内做更多的事
        • 定义：研究管理活动中基本管理关系、管理规律及一般方法的科学；是一门综合性的交叉学科
        • 中心议题 ★：管理者如何有效管理其组织；让一群平凡的人创造出不平凡的组织业绩
          • 微观（单个组织）：工业企业管理学 / 社团管理学
          • 中观（一类组织）：工业经济管理学 / 行业管理学
          • 宏观（一群组织）：国民经济管理学 / 非营利性组织管理学
          • 基础（所有组织）：管理学
        • 管理学是整个管理学科体系的基石：管理科学与工程、工商管理、公共管理、图书情报与档案管理、农林经济管理
        • 学习意义：了解管理的一般规律；形成理性分析能力与直觉判断能力；指导管理实践、提升管理水平
          • 战略思维：高瞻远瞩，统揽全局
          • 历史思维：以史为鉴，认识发展规律
          • 辩证思维：看到矛盾，抓住重点，洞察规律
          • 创新思维：因时制宜，知难而进，敢为人先
          • 底线思维：守住道德法律底线，目标难以实现时事先做好调整
          • 法约尔：五职能，即计划、组织、指挥、协调、控制
          • 孔茨与奥唐内尔（20 世纪 50 年代）：计划、组织、人员配备、指导、控制
          • 后来多数教材：四职能，即计划、组织、领导、控制
          • 2000 年以后：七职能，即信息获取、决策、计划、组织、领导、控制、创新
          • 本教材：计划（决策）、组织、领导、控制、创新
          • 决策（计划）：确立目标、制订行动方案，着眼于有限资源的合理配置
          • 组织：组织设计、人员配备、权力配置，着重于合理分工与明确协作关系
          • 领导：指导、协调、激励，致力于调动积极性、把握方向
          • 控制：检查和监督，着力于纠偏
        • 职能之间的关系：决策与计划 → 组织 → 领导 → 控制，循环往复；创新融入每个环节；管理者需时时观察环境做调整
        • 管理是一个系统过程：由有限资源出发，四大职能循环并反馈，实现管理目标；低浪费（讲效率）、高成就（讲效益）
        • 判断标准：在组织中担任管理角色（有头衔、正式任命）；从事管理工作、履行四大职能；有直接下属，负责指挥下属开展工作
        • 定义 ★：在组织中组织开展管理工作并对组织绩效负责的人
          • 高层：对组织整体运作负责，制定战略与目标，代表组织对外交往，确定发展方向和使命
          • 中层：组织的中坚力量，贯彻高层意图，把任务落实到基层，检查督促和协调基层工作
          • 基层：处于最前线，管理生产、作业和其他业务工作
          • 主要观点：管理者需要在不同角色之间转换；角色是属于一定职责或地位的一套有条理的行为
          • 十种角色构成整体：正式权力和地位 → 人际角色 → 信息角色 → 决策角色
          • 人际角色：代表人、领导者、联络者（源于正式权力）
          • 信息角色：监督人、传播者、发言人（信息传递中心）
          • 决策角色：企业家、冲突管理者、资源分配者、谈判者
          • 领导者角色是十种角色中最显著的一种，是管理者权力最明显的表现
          • 技术技能：掌握和熟悉特定专业领域的过程、惯例、技术和工具的能力
          • 人际技能：成功地与别人打交道并与别人沟通的能力
          • 概念技能：产生新想法并加以处理，以及将关系抽象化的思维能力
          • 比例 ★：高层最需要概念技能，基层最需要技术技能，人际技能对各层都重要
        • 本质 ★：管理是对人或人的行为的管理，本质是对人的行为进行协调
          • 科学性：在长期总结管理工作客观规律的基础上形成一系列管理原则和理论，以理论为指导、根据实际行事
          • 艺术性：管理者在实践中对管理理论运用的灵活性和对管理方法选择的技巧性
          • 自然属性：社会生产靠共同劳动，不进行有效管理社会就无法发展；同生产力、社会化大生产相联系
          • 社会属性：协调共同劳动需体现生产资料所有者的指挥和监督，体现生产关系；同生产关系、社会制度相联系
          • 依靠人的管理：组织被管理者参与管理；重视管理的人性化
          • 为了人的管理：更好满足服务对象的要求；全体成员共享组织成果的改善
          • 系统：若干相互依存、相互作用的要素或子系统组成的、具有特定功能的有机整体
          • 分类：按形成方式分自然系统 / 人造系统；按是否与环境交互分封闭系统 / 开放系统；按状态是否变化分静态系统 / 动态系统
          • 社会经济组织系统的特征：整体性、相关性、有序性、与外部环境的互动性
          • 应用：每个问题都是系统中的问题；必须有层次观点；必须有开发观点
        • 效益原理：做正确的事 + 正确地做事，既讲效率又讲效果
        • 适度原理：在两个极端之间找到最恰当的点，实现适度组合，如专业化与多样化、分权与集权、扁平化与层级制
          • 按管理对象：与人、与物、与资金、与活动组织有关的方法
          • 按活动阶段：方案制定、方案比较、方案实施、过程控制方法
          • 按管理层次：宏观、中观、微观管理方法
          • 按属性：法律、行政、经济、教育方法
        • 基本方法 ★：理性分析 + 直觉判断
          • 权力：组织中个体之间在一定时期内相对稳定的关系；理解为命令与服从则是单向关系，理解为影响力则是双向关系
          • 权力关系的基本特征：不完全平等的权力地位
          • 权力资源：专门知识或技能、经验和能力、个人品质、奖励或惩罚他人的可能性
          • 组织文化：核心是成员普遍认同、共同接受的价值观念及其决定的行为准则；影响持续、普遍、低成本，作用是无意识的
        • 管理是历史范畴；全球化和信息化是当今世界的两大重要特征；中国改革开放后市场化成为主旋律
        • 全球化：关注不同文化之间人员和思想的互动（南希·阿德勒）
        • 信息化：ERP、CRM、SCM、OAS、云平台、大数据
        • 市场化：现代企业制度，即产权明晰；企业以法人财产依法自主经营、自负盈亏；出资者按投入资本额享有权益；按市场需求组织生产；建立科学的领导体制和管理制度
          • 实践上：资本家及其代理人凭个人经验管理，工人凭经验操作，缺乏统一规程和严格制度
          • 理论上：只有零星研究，尚未形成系统理论
          • 特点：资本家直接担任管理者；靠个人经验管理；管理重点是解决分工与协作问题
          • 传统管理要点：顺"道"、重人、人和、守信、利器、求实、对策、节俭、法治
          • 思想来源：儒家（仁义礼智信）、道家、法家、佛家
          • 代表名句：得道多助，失道寡助；天时地利人和；运筹帷幄，决胜千里之外；君子信而后劳其民；静以修身，俭以养德
          • 地位 ★："科学管理之父"（1856-1915），科学管理又称"泰勒制"，是关于生产组织合理化和作业标准化的科学方法
          • 两大核心：管理要走向科学（以科学化、标准化方法代替经验管理）；劳资双方的心理革命（双方利益一致，相互协作才能提高绩效）
            • 劳动使用不当 → 改进工作方法，按要求挑选和培训工人
            • 工人不愿多干 → 改进分配方法，实行差别计件工资制
            • 生产组织与管理问题 → 改进生产组织，加强企业管理
            • 工作定额原理：通过时间研究和动作研究找出科学的工作方法，并据此确定合理的工作定额
            • 标准化原理：操作方法、工具、机器、材料和作业环境都标准化
            • 能力与工作相适应：挑选"第一流的工人"，即兼具能力与意愿的工人
            • 差别计件工资制：在科学制定定额的前提下，鼓励工人完成或超额完成定额
            • 计划职能与执行职能相分离：由计划部门制定计划和标准，工人和工长负责执行
          • 四项科学管理原则：用科学方法代替经验；科学地挑选和培训工人；与工人密切合作，确保按科学原则办事；管理者和工人的工作与职责大致均分
          • 其他代表：吉尔布雷斯夫妇（动作研究、工作简化）；甘特（甘特图、计件奖励工资制）
          • 地位 ★："现代管理之父"（1841-1925），管理过程学派的理论基础；代表作《工业管理与一般管理》
          • 经营六大职能 ★：技术、商业、财务、安全、会计、管理；管理只是经营的一部分
          • 五大管理职能：计划、组织、指挥、协调、控制
          • 十四条管理原则 ★：劳动分工、权力和责任、纪律、统一指挥、统一领导、个人利益服从整体利益、人员报酬、集中、等级制度、秩序、公平、人员稳定、首创精神、人员团结
          • 三大贡献：提出管理的普遍性；提出适用于一切组织的管理职能论；提出在大学开设管理课程的思想（管理能力可以通过教育获得）
          • 地位 ★："组织理论之父"（1864-1920），提出"理想的行政组织体系理论"；代表作《社会和经济组织的理论》
          • 科层制：通过公职或职位，而不是世袭或个人魅力来管理的理想组织制度
          • 六大特征 ★：劳动分工、职权层级、正式选拔、正式规章制度、非人性化、职业导向
            • 传统型权力：建立在对习惯和古老传统神圣不可侵犯的要求之上
            • 个人魅力型权力：建立在对英雄人物或神授品质的个人崇拜之上，不能作为稳固制度的基础
            • 法理型权力：对法律确定的职位或地位的服从；只有它能作为科层组织的基础
        • 古典理论的共同特点：研究重点是如何提高效率；主张用科学代替经验；主张管理专业化、职业化（管理与操作分离、专门的管理教育）
          • 人是"社会人"，不是单纯的"经济人"
          • 企业中存在"非正式组织"，维护其成员的共同利益
          • 提高劳动生产率的首要因素是工人的"满意度"，生产条件、工资报酬居第二位
          • 代表作：《工业文明中人的问题》《工业文明的社会问题》
        • 人性假设的演变P221：传统模式 → 人际关系模式 → 人力资源模式
          • 经济人假设（X 理论）：人追求个人利益最大化；人是自利的但不是孤立的；自利本性不变
          • 社会人假设（霍桑实验）：社会需求比经济报酬更能激励人；工作效率随上司满足其社会需求的程度而变化
          • 自我实现人假设（Y 理论）：依据马斯洛"自我实现是最高需要"；大多数人乐于工作、能自我控制、会主动寻求责任，潜力大且只发挥了一小部分
          • 复杂人假设（超 Y 理论，沙因；莫尔斯和洛什提出超 Y 理论）：人既非单纯经济人、社会人，也非纯粹自我实现人；强调主体需要的差异性、组织方式的相异性、控制程度的应变性、目标确立的递进性
          • X 理论：人性本恶，厌恶工作、逃避责任，必须严加监管
          • Y 理论：人性本善，善加诱导便会热诚工作，并主动寻求责任
        • 行为管理思想的特点：把人看作宝贵的资源；从人的需求、动机、相互关系和社会环境研究管理；协调人的目标、激励积极性，以提高效率
          • 把组织及其成员的相互关系看成一个协作的社会系统，被称为社会系统学派创始人；代表作《经理人员的职能》（1938）
          • 组织是两个或两个以上的人有意识协调活动和效力的系统
          • 协作系统三要素：协作的意愿、共同的目标、信息的沟通
          • 经理人员的职能：建立和维持信息系统；从成员那里获得必要的服务；规定共同目标并分解到各部门
          • 代表人物：菲德勒，代表作《领导与有效管理》
          • 要点：不存在一成不变、普遍适用的管理理论和方法，管理应随机应变，采用什么方法取决于组织环境
          • 管理学者的任务：归纳出管理情境由哪些因素组成、有哪些状态、对应哪些管理方法
          • 西蒙：管理的本质是决策，决策贯穿整个管理过程；受认知能力、时间、经费、信息的限制，只能做出"足够好的"或"令人满意的"决策 ★
          • 明茨伯格：组织管理的基本问题是分工与协调；组织结构是劳动分工和协调方式的总和；六种协调机制为相互调适、直接监督、工作程序标准化、成果标准化、技能与知识标准化、规范标准化
          • 观点：管理就是制定和运用数学模型与程序的系统，用数学方法求出最优解
          • 四个前提假设：组织成员是经济人；组织是追求经济效益的系统；组织是人与物质技术设备组成的人机系统；组织是一个决策网络
          • 解决问题的程序：观察和分析 → 确定问题本质 → 建立数学模型 → 找出最优解 → 验证最优解 → 建立控制 → 实践方案
        • 经验管理（实践经验）→ 科学管理（科学方法）→ 行为管理（人的重要性）→ 定量管理（数量化）→ 权变管理（环境因素）
        • 中心议题始终是：管理者如何有效管理其组织
